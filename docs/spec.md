## 1. プロダクト概要

| 項目 | 内容 |
|------|------|
| プロダクト名 | masker（仮称） |
| プロダクトID | 003 |
| 種別 | CLIツール |
| 対象OS | Windows 11（MVP） / Linux（将来対応） |
| 実装言語 | Python（MVP） → Rust（リライト候補・別途検討） |
| 配布形式 | 単一実行ファイル（.exe） / PyInstallerで生成 |

### コンセプト

テキストデータ内の個人情報や機密情報をパターン認識で検知し、自動的にマスキング処理を行うCLIツール。完全ローカル処理。外部APIへの通信は一切行わない。

---

## 2. 対象ユーザー

- テキストデータを扱うフリーランスエンジニア・ITコンサルタント
- 画面共有・ログ提出・議事録共有前に機密情報を除去したい技術者
- 中小企業の情報システム担当者

## 4. マスキング対象パターン仕様

### 4-1. MVP対象パターン一覧

| パターンID | 種別 | パターン例 | デフォルト |
|------------|------|------------|------------|
| P01 | メールアドレス | user@example.com | ON |
| P02 | 電話番号（固定・携帯） | 03-1234-5678 / 090-1234-5678 | ON |
| P03 | 郵便番号 | 〒100-0001 / 100-0001 | ON |
| P04 | クレジットカード番号 | 1234-5678-9012-3456 | ON |
| P05 | マイナンバー | 1234 5678 9012 | ON |
| P06 | IPアドレス（IPv4） | 192.168.0.1 | ON |

### 4-2. v0.2以降の対象パターン（MVP対象外）

| パターンID | 種別 |
|------------|------|
| P07 | 氏名（辞書ベース） |
| P08 | 銀行口座番号 |
| P09 | パスポート番号 |
| P10 | カスタム正規表現（ユーザー定義） |

### 4-3. マスキング文字仕様

- デフォルトマスキング文字: `***`
- マスキング形式: パターン全体を一括置換（部分置換不可）
- 例: `user@example.com` → `***`
- CLIオプションで任意の文字列に変更可能（例: `[REDACTED]`）

## 5. 出力仕様

### 5-1. 出力先

| 出力先 | 指定方法 | MVP対応 |
|--------|----------|---------|
| 標準出力（stdout） | オプションなし（デフォルト） | ✅ |
| ファイル出力 | `-o` オプションで出力パスを指定 | ✅ |
| 元ファイル上書き | `--inplace` オプション | ❌ v0.2以降 |

### 5-2. サマリーレポート出力

処理後に以下のサマリーを **stderr** に出力する（stdoutと分離するため）。

```
[masker] 処理完了
  検出件数: 12件
    P01 メールアドレス : 3件
    P02 電話番号       : 5件
    P04 クレカ番号     : 1件
    P06 IPアドレス     : 3件
  出力先: output.txt
```

`--quiet` オプション指定時はサマリーを出力しない。

## 6. CLIインターフェース仕様

### 6-1. 基本構文

```
masker [OPTIONS] [INPUT]
```

### 6-2. 引数・オプション一覧

| オプション | 短縮形 | 説明 | デフォルト |
|------------|--------|------|------------|
| `[INPUT]` | - | 入力ファイルパス。省略時はstdinを使用 | stdin |
| `--output PATH` | `-o` | 出力ファイルパス。省略時はstdout | stdout |
| `--mask TEXT` | `-m` | マスキング文字の指定 | `***` |
| `--only P01,P02,...` | - | 指定パターンのみ有効化 | 全パターンON |
| `--exclude P01,P02,...` | - | 指定パターンを無効化 | なし |
| `--quiet` | `-q` | サマリー出力を抑制 | OFF |
| `--version` | `-v` | バージョン表示 | - |
| `--help` | `-h` | ヘルプ表示 | - |

### 6-3. 使用例

```bash
# ファイルを処理してstdoutに出力
masker input.txt

# ファイルを処理してファイルに出力
masker input.txt -o output.txt

# パイプ経由で使用
cat log.txt | masker -o cleaned.txt

# マスキング対象をメールアドレスと電話番号のみに限定
masker input.txt --only P01,P02

# クレカ番号パターンだけ除外
masker input.txt --exclude P04

# マスキング文字を変更
masker input.txt -m "[REDACTED]"

# サマリーを抑制してstdoutのみ出力
masker input.txt -q
```

## 7. エラー仕様

| エラーケース | 終了コード | メッセージ例 |
|--------------|------------|--------------|
| 正常終了 | 0 | - |

| 非対応の文字コード | 2 | `[ERROR] 非対応の文字コードです（UTF-8のみ対応）` |
| 不正なオプション指定 | 3 | `[ERROR] 不正なオプションです: --xxx` |

## 8. 非機能要件

| 項目 | 要件 |
|------|------|
| 処理速度 | 1MBのテキストファイルを3秒以内に処理 |
| 検出精度 | 各パターンで誤検知率5%以下を目標（MVPはベータ明示で許容） |
| インストール | 単一exeファイルのコピーのみで動作（インストーラー不要） |
| 外部依存 | ランタイム・外部APIへの依存なし・完全ローカル処理 |
| パス制約 | プロジェクトフォルダパスに日本語・全角文字を含めないこと |

## 11. 実装方針・注意事項

- 言語はPython（MVP）。Rustリライトは完成後に別途判断する
